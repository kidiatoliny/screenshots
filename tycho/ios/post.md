## Text: LinkedIn

Tycho runs on iPhone from the same SwiftUI code as the Mac.

That doesn't mean the same layout. On the iPhone, Home is a grouped form with the workspace counts and My tasks, Settings moved into the sidebar's navigation bar, and search stays in the trailing toolbar group so it doesn't get pushed out. On the Mac the same screens use the Mac's own controls.

What I keep relearning: sharing the code is easy. Making each platform feel like it was built for itself is where the time goes.

Tycho is open source, built for my own work first.
