# Tycho: shot list

Source: https://github.com/akira-foundation/tycho (native SwiftUI task manager for iOS 27 and macOS 27, SwiftData, on-device). Build from an up-to-date main with `make build` and run the `Tycho` scheme. Use the demo data only. Take window-only `screencapture` on Retina, never cropped or edited. The post that uses a feature's shots goes in that feature's folder as `post.md` (written by Claude).
