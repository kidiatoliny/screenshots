# Tycho: what it is

Planned: 2026-11-09 08:30 Luxembourg (LinkedIn)

## Text: LinkedIn

I'm building Tycho, a native task manager for macOS 27 and iOS 27, written in SwiftUI and named after Tycho Brahe.

One set of tasks, five ways to look at it: a board you drag cards across, a list, a table whose columns you sort, resize and hide, a calendar where you drag a task to another day, and a timeline with dependency arrows and milestones.

It uses SwiftData and keeps everything on the device. The code is open source under MIT and Apache 2.0.

My rule for side projects these days: build for the ecosystem I use, Apple, to fix my own problems, and leave the code open in case it fixes yours.
