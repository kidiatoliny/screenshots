# Tycho: the table view

Planned: 2026-11-11 10:00 Luxembourg (X + Bluesky)

## Text: X

Tycho's table view: click a title and you edit it in place. Status, priority, assignee, dates, labels, dependencies and estimate edit inline too. Columns sort, resize and hide, and each view remembers its own. On iPhone the rows become cards.
