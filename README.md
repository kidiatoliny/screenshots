# screenshots

Screenshots of my apps and the social posts that use them. One folder per app:

```
<app>/
  SHOTLIST.md                      screens to capture and their status
  <feature>/NN-<what-it-shows>.png the original screenshot (Retina)
  <feature>/NN-<what-it-shows>.jpg the version used in posts (< 900 KB, generated by .github/workflows/social-jpeg.yml)
  posts/README.md                  index of the app's posts
  posts/YYYY-MM-DD-<slug>/post.md  one post: schedule, text per channel, Buffer IDs, links, screenshots used
```

`scenarios/` holds the demo data the test builds are opened with.

## Screenshot rules

- Taken from a test build of an up-to-date `main`, with demo data only. No emails, tokens or private repositories on screen.
- Window only, with `screencapture`, on a Retina display. Never cropped or edited by hand.
- Never add a `.jpg` by hand: the workflow generates it from the `.png`.

## Using an image

```
https://raw.githubusercontent.com/kidiatoliny/screenshots/main/<app>/<feature>/<file>.jpg
```
