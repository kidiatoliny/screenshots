# screenshots

Screenshots of the apps I build, organised by app and feature. They're used in social posts, READMEs and docs.

## Layout

```
<app>/<feature>/<NN>-<what-it-shows>.png
```

Example: `unified-dev/archive/01-safety-report.png`

Each app folder has a `SHOTLIST.md` with the screens that are still missing and the date they're needed by.

## Conventions

- PNG, window only (Cmd+Shift+4, then Space, then click the window).
- Light or dark, but the same mode across one feature.
- Numbered in the order a reader should see them.
- No personal data: hide emails, account names, tokens and private repo names before taking the shot.

## Using an image

Every file has a stable public link:

```
https://raw.githubusercontent.com/kidiatoliny/screenshots/main/<app>/<feature>/<file>.png
```
