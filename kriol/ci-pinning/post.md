# Kriol: Actions e toolchains fixados por hash

## Text: X

Mais duas no Kriol, do lado da cadeia de fornecimento: as GitHub Actions passam a ser referidas pelo SHA do commit, e os toolchains do CI de Windows só são extraídos se o SHA256 bater. O runtime do MinGW entra em todos os programas compilados, por isso isto conta.
