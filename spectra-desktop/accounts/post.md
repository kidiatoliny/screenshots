# Spectra: saved accounts with TOTP

Planned: Bluesky 11/12 10:00, X 11/12 10:00 (Europe/Luxembourg)

## Text: X

Testing an API as different users means juggling logins. Spectra saves accounts with their bearer token, password, API key or cookies, and can generate the TOTP code for one that has two-factor on. All encrypted, on your machine.
