# Orbit: one app instead of five terminals

## Text: X

Orbit is my answer to five terminals running npm run dev. Add a local project once and it gets a .test domain. Orbit works out the package manager and the framework, reads the scripts in package.json and suggests the dev command. Built with Go and Wails.
