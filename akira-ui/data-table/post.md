# Akira UI: naming the data table's controls

## Text: X

An accessibility fix in Akira UI's data table: the row actions button, the previous and next page buttons and the rows-per-page select showed up as unnamed controls to screen readers. Each now has a label, translated in pt, es and fr, and you can override it through props.
