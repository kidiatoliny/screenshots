## Text: LinkedIn

Most React apps start the same way: a sidebar, a header, a user menu, and an afternoon spent wiring them together.

Akira UI, my component library on top of shadcn/ui, ships that as a block. The application shell gives you the sidebar, header and user menu already put together, and the sidebar collapses down to icons. A new app starts from a working layout instead of an empty page.

Blocks are the part I'm adding the most to: components tell you how a button looks, blocks tell you how a screen fits together.

https://ui.akira-io.com
