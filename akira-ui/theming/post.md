# Akira UI: your brand with one CSS import

Planned: 2026-11-13 08:30 Luxembourg (LinkedIn)

## Text: LinkedIn

Akira UI is my React component library: the full shadcn/ui set on OKLCH design tokens, purple by default.

To put your own brand on it, you import one CSS file and leave the components alone. The two screenshots are the same page before and after: same layout, and the button, the selected item and the highlights change colour.

I wanted theming to be something you do once, at the edge of the app, instead of a prop on every component.

How do you handle branding in your component library?
