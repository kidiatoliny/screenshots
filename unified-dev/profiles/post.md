# Unified Dev: profiles

Planned: 2026-11-16 08:30 Luxembourg (LinkedIn)

## Text: LinkedIn

Unified Dev now groups projects into profiles.

A profile owns its projects, their workspaces and a folder under the workspaces root. The window shows one profile at a time. Switch from the sidebar, or with Control-Command and a digit, and the window, the menu bar panel and the notifications change. No agent stops when you switch.

A project moves between profiles with its workspaces and chats. The MCP bridge answers each caller for its own profile, and an Ask chat stays in the profile its turn began in.

The migration only adds: every existing project lands in the first profile, and an older build refuses the migrated database instead of misreading it. Accounts per profile come next.

How do you keep client work and your own projects apart?
