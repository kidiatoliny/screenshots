# Unified Dev: account in the model menu

Planned: 2026-11-17 18:00 Luxembourg (X + Bluesky)

## Text: X

In Unified Dev the agent's account now sits in the model menu, under Account, and only when that agent has two or more accounts on the Mac. The choice is per project: every workspace and chat in it runs the same account.
