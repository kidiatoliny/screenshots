# Unified Dev: the canvas editor

Planned: 2026-11-18 18:00 Luxembourg (X + Bluesky)

## Text: X

The canvas tab in Unified Dev now has its own editor: text, notes, shapes, pen, frames, images, PNG export and undo. Comments you place on the canvas reach the agent when it's idle, and wait in a queue while it works.
