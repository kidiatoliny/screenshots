# Unified Dev: what it is

## Text: X, Bluesky

Something I've been building: Unified Dev, a native macOS app for running coding agents in parallel, each one in its own git worktree. Built with SwiftUI. Projects on the left, the agent transcript in the middle, a terminal and the diff on the side.

# Unified Dev em português

## Text: X

Estou a fazer o Unified Dev, uma app nativa para macOS onde corro vários agentes de código ao mesmo tempo. Cada um trabalha no seu git worktree, num branch só dele, por isso nunca mexem nos ficheiros uns dos outros. É em SwiftUI e o código é aberto.
